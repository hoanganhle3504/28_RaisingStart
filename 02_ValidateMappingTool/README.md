# ECU-TEST PRJ Matrix Validator

A specialized GUI automation tool for auditing and injecting missing K-Matrix parameters (BitPos, DefaultValue, Conversion) into ECU-TEST project files (.prj).

---

## Quick Start
To launch the tool, simply double-click:
👉 **ECU-TEST_PRJ_Matrix_Validator.exe**

*(No Python installation or command-line setup required!)*

---

## Directory Structure
- **ECU-TEST_PRJ_Matrix_Validator.exe**: Standalone Windows desktop application.
- **README.md**: This quick-start guide.
- **Other/**: Contains Python source code, automated unit tests, batch launcher, and in-depth architecture documentation (ARCHITECTURE.md).
